📦 GITHUB REPOSITORY (public — sadece referans, key icermez)

Bu repo'da .env.example, team.py, INDEX, agents, hooks, settings sablonlari var. Gercek .env (key'li) commit edilmez — .gitignore koruyor.
git clone https://github.com/Sansar35/claude-agent.git
Yeni makinede sifirdan kurmak icin: git clone → copy .env .env.local → key'leri yapistir → python test.py
📋 1) .env DOSYASINI AC (KEY YAPISTIRMA)
notepad %USERPROFILE%\.claude\repos\team\.env.local
.env.local dosyasi acilir (gercek key'lerin orada saklanir, .gitignore koruyor). Karttan kopyaladigin KEY= satirini yapistir, sonuna anahtarini ekle, Ctrl+S.
📋 2) AKTIF KEY DURUMUNU GOR
cd %USERPROFILE%\.claude\repos\team && python test.py
Hangi key girildi, kac worker aktif olduğunu gosterir.
📋 3) PARALELLIK DEMOSU (HEPSI BIR ANDA CALISIYOR MU GOR)
cd %USERPROFILE%\.claude\repos\team && python demo.py
Her ajan kisa soruyu cevaplar, BASLAMA/BITME zamanlarini ASCII bar grafiginde gosterir.
📋 4) VERIFY — KEY'LERIN GERCEK ISTEK ATTIGINI KANITLA
chcp 65001 && cd /d %USERPROFILE%\.claude\repos\team && python verify.py
Her aktif ajana 1 saniyelik 'pong' istegi atar. Latency > 0 + token gelirse = gercekten aktif.
📋 5) TUM EKIBI CALISTIR (PARALEL URETIM)
chcp 65001 && cd /d %USERPROFILE%\.claude\repos\team && python team.py "FastAPI ile JWT login API yaz"
Lider Opus plan yapar → tum AI'lar paralel kod yazar → Lider sentezler.
